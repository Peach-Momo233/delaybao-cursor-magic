delay宝指针大法 1.0.3
Ubuntu 20.04 / GTK3 兼容版
============================================

一、程序简介

delay宝指针大法用于把 Windows 鼠标指针转换成 Linux Xcursor
主题，并完成用户级安装、切换和大小调整。

本版本使用 GTK3 和 Python 3.8 兼容语法，主要面向 Ubuntu 20.04。
程序不会修改 /usr/share/icons 中的系统光标主题，也不需要以 root
身份运行。


二、主要功能

- 拖放或选择 ZIP、INF、ANI、CUR 文件。
- 自动识别普通、链接、文本、等待、移动和缩放等光标角色。
- 转换、安装并启用 Xcursor 主题。
- 使用滑杆调整 GNOME 光标大小。
- 保存历史安装记录，一键切换以前安装过的皮肤。
- 可以只删除某条历史记录，不删除电脑里的主题文件。
- 可以恢复 Ubuntu 的 Yaru 默认主题。
- 可以一键卸载本程序最后管理的光标主题。


三、安装

推荐双击以下安装包，通过 Ubuntu 软件安装器安装：

delay宝指针大法_1.0.3_ubuntu20.04_gtk3_all.deb

也可以在安装包所在目录打开终端，运行：

sudo apt install ./delay宝指针大法_1.0.3_ubuntu20.04_gtk3_all.deb

APT 会自动处理以下依赖：

- Python 3.8 或更高版本
- python3-gi
- GTK3 GObject Introspection
- python3-pil（Pillow）
- GTK3 运行库

Debian 包名：

delaybao-cursor-magic-gtk3


四、启动

安装后可在 Ubuntu 应用菜单中搜索：

delay宝指针大法

也可以在终端运行：

delaybao-cursor-gtk3

注意：“delay宝指针大法”是应用菜单中的显示名称，不是终端命令。

如果应用菜单没有立即出现，可注销并重新登录，或先使用终端命令启动。


五、安装鼠标皮肤

1. 把 ZIP、INF、ANI 或 CUR 拖入米黄色区域，或者点击“选择皮肤文件”。
2. 点击“转换并安装”。
3. 等待进度条显示安装完成。
4. 新主题会自动启用。

转换后的用户主题一般保存在：

~/.icons/Delaybao-主题标识/

程序只会在当前登录用户的主目录中安装主题，不影响其他用户。

如果重新安装同一个压缩包，会覆盖该压缩包以前生成的同名主题。


六、光标大小

滑杆范围为 16–96。主题内部包含从 16 到 96、每 4 像素一档的
实际 Xcursor 图像。

部分 X11、远程桌面、虚拟机或启用了整数/分数显示缩放的系统，可能会
对光标大小再次乘以显示缩放系数。因此同一个滑杆数值在不同电脑上的
视觉大小可能不同。

部分已经打开的程序不会立即重新载入光标。遇到这种情况时：

1. 把鼠标移动到另一个窗口再移回来。
2. 关闭并重新打开相关程序。
3. 必要时注销并重新登录。


七、历史安装

点击“历史安装”会打开历史窗口。

- 点击皮肤名称：切换到对应的已安装主题。
- 点击“删除记录”：只删除历史路径记录和对应按钮。

“删除记录”不会删除 ~/.icons 中的主题文件。这和“一键卸载”是两种
不同操作。

如果历史记录指向的主题文件已经不存在，切换时会提示路径无效，此时
可以安全地删除该记录。

历史记录保存在：

~/.config/delaybao-cursor/state.json


八、恢复默认与一键卸载

“恢复默认”会：

- 把光标主题切回 Yaru。
- 把光标大小恢复为 24。
- 保留程序安装的主题和历史记录，之后仍可再次切换。

“一键卸载”会：

- 如果当前正在使用该主题，先切回 Yaru。
- 删除本程序记录的对应用户主题文件。
- 删除该主题的历史记录。

程序不会通过“一键卸载”删除 Yaru 或其他系统主题。


九、升级

安装相同包名的新版本时，不需要先卸载旧版本。例如：

sudo apt install ./新版安装包.deb

新版本会覆盖程序文件，但不会主动清除以下用户数据：

- ~/.icons 中已经转换的主题
- ~/.config/delaybao-cursor/state.json 中的历史记录

如果新版本改进了转换格式，需要重新拖入原始皮肤并点击一次
“转换并安装”，旧主题文件才会按新规则重新生成。


十、卸载程序

仅卸载程序，保留用户配置：

sudo apt remove delaybao-cursor-magic-gtk3

卸载程序并清除由 Debian 包管理器管理的系统级配置：

sudo apt purge delaybao-cursor-magic-gtk3

注意：APT 不会自动删除当前用户主目录中的光标主题和历史记录，包括：

~/.icons/Delaybao-主题标识/
~/.config/delaybao-cursor/state.json

这是为了避免卸载程序时误删用户已经转换好的皮肤。

如果只是想删除某个主题，建议先在程序中切换到其他主题，再使用
“一键卸载”。不要直接删除当前正在使用的主题目录。


十一、常见问题

1. 终端提示“delay宝指针大法：未找到命令”

   应使用英文启动命令：

   delaybao-cursor-gtk3

2. 点击安装后仍显示旧光标

   检查当前主题：

   gsettings get org.gnome.desktop.interface cursor-theme

   正常情况下应显示以 Delaybao- 开头的主题标识。部分程序需要关闭后
   重新打开，桌面会话必要时需要注销再登录。

3. 光标大小数值变化，但视觉大小没有按预期变化

   检查：

   gsettings get org.gnome.desktop.interface cursor-size
   xrdb -query | grep -i cursor

   X11 显示缩放可能使 Xcursor.size 和滑杆数值不同，这属于系统显示
   配置行为。

4. “一键卸载”按钮不可用

   该按钮只管理通过本程序安装并记录的主题。手动复制到 ~/.icons 的
   主题不会自动纳入卸载记录。

5. 无法打开压缩包

   确认压缩包中包含 ANI 或 CUR 文件。程序会忽略无关文件，并限制异常
   大小或异常文件数量的压缩包，以降低恶意压缩包风险。


十二、安全与隐私

- 转换在本机完成，不会上传鼠标皮肤。
- 不要求 sudo 权限来转换或安装用户主题。
- 只接受 ZIP、INF、ANI 和 CUR 输入。
- 对 ZIP 路径穿越、异常文件数量和解压总大小进行限制。
- “删除记录”绝不会删除主题文件。
- “一键卸载”只允许删除本程序使用 Delaybao- 标识管理的主题。


十三、开发文件

源码开发目录应完整保留，以便继续修改和重新打包：

delay宝指针大法-ubuntu20.04/

主要文件：

- app.py：GTK3 图形界面
- converter.py：ANI/CUR 到 Xcursor 的转换器
- style.css：粉蓝糖果色样式
- bow.svg：像素蝴蝶结图标
- hearts.svg：三颗像素爱心
- packaging/：Debian 打包元数据
